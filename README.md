# Analysis code for long-term mowing experiment in Phalaris arundinacea

This repository contains the R scripts used to generate the main and supplementary figures in the manuscript.

## Code–figure mapping

- Figure 1: `01_Fig1A_long_term_trajectories.R`, `02_Fig1BC_yield_predictor_importance.R`
- Figure 2: `03_Fig2AB_random_forest_Boruta_key_taxa.R`, `04_Fig2C_key_taxa_profile_contribution.R`
- Figure 3: `05_Fig3A-D_RT_taxa_regressions.R`, `06_Fig3E_RS_RT_BS_association_network.R`, `07_Fig3FG_root_metabolite_pathway_analysis.R`
- Figure 4 and Figure S2: `08_Fig4_and_FigS2_RT_functional_coexpression_PLS.R`
- Figure 5: `09_Fig5_SEM_and_shared_variance.R`
- Figure S1: `10_FigS1_NMDS_and_ternary_enrichment.R`
- Figure S3: `12_FigS3_extended_yield_path_sensitivity_SEM.R`

## Software

Analyses were performed in R. Required packages are specified within each script.

## Data availability

Source data are not included in this repository.

## Notes

The scripts are provided to document the analytical procedures used in the manuscript.
